## 🎯 About

**YT-Downloader** is a powerful, user-friendly desktop application that lets you download YouTube videos and audio with just a few clicks. Features automatic format conversion, bilingual support (English & Arabic), and a beautiful dark/light theme interface.

Download videos as **MP4** and audio as **MP3** automatically. No manual conversion needed!

---

## ✨ Key Features

### 🎬 **Video & Audio Download**
- Download videos from YouTube in various qualities (up to 4K)
- Extract audio directly as high-quality MP3 (320kbps)
- Support for 60 FPS and 30 FPS options for videos
- Real-time progress tracking with speed and ETA

### 📹 **Automatic Format Conversion**
- Videos automatically convert to `.mp4` format
- Audio automatically converts to `.mp3` at 320kbps

- Download history with persistent storage

## 📖 Usage

### Basic Download

1. **Paste URL**
   - Copy YouTube video link
   - Paste into the URL field
   - Or use the clipboard button 📋

2. **Select Type**
   - Choose "Video" or "Audio"
   - Quality and FPS options appear

3. **Choose Quality**
   - **Video:** 4K Ultra, 2K Quad, Full HD, HD 720p, SD 480p, SD 360p
   - **Audio:** MP3 320kbps
   - **FPS:** 60 FPS or 30 FPS

4. **Download**
   - Click the red **DOWNLOAD** button
   - Watch progress in real-time
   - Status: Downloading → Converting → Completed

5. **Access Files**
   - Click "Open File" to play immediately
   - Click "Open Location" to browse folder

### Settings Configuration

**Access Settings:** Click the ⚙️ Settings button

| Setting | Options |
|---------|---------|
| **Language** | English / العربية |
| **Theme** | Dark / Light |
| **Accent Color** | Red / Blue / Green |
| **Download Path** | Any folder |

**Click "Save Changes" to apply all settings!**

## 🐞 Troubleshooting

### Downloads fail
1. Check internet connection
2. Verify YouTube URL is valid
3. Ensure download folder has write permissions
4. Restart the application

### Open File button not working
1. Verify file exists in download folder
2. Ensure media player is installed
3. Try Open Location and play from there

### Language not switching
1. Close and reopen Settings
2. Restart application
3. Try selecting language again

### Converting takes too long
1. Normal for large files
2. FFmpeg processes in real-time
3. Don't close application during conversion
4. Check available disk space
