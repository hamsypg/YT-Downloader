# 🚀 YT-Downloader

**YT-Downloader** is a high-performance, seamless bridge between your browser and your desktop. No more copying and pasting links. Download YouTube videos in **4K, 1080p**, or high-quality **MP3** directly from the YouTube player with a single click.

## ✨ Key Features

- **🎯 Direct Integration:** Adds a professional "Download" button directly into the YouTube video player controls.
- **💎 Glassmorphism UI:** A modern, beautiful desktop interface with a transparent glass effect.
- **⚡ Smart Protocol Bridge:** Uses a custom `ytdl://` protocol to instantly wake up the desktop app from your browser.
- **🎥 Ultra HD Support:** Support for 4K, 1080p, 720p, and high-bitrate MP3 audio extraction.
- **🌍 Multilingual:** Full support for **English** and **Arabic** with a native Right-to-Left (RTL) layout.
- **🚀 One-Click Install:** Smart registry integration that automatically associates the tool with your system.

---

## 🛠️ How It Works

This project consists of two parts working in perfect harmony:
1.  **The Browser Extension:** Detects the video and provides the download menu inside YouTube.
2.  **The Desktop App:** A lightweight Python-powered tool (built on `yt-dlp`) that handles the high-speed downloading and conversion.

## 📥 Installation Guide

### 1. Install the Browser Extension
Install the official **YT-Downloads Helper** from the [Microsoft Edge Add-ons Store](COMING SOON). 
*(Note: After installation, you will be automatically redirected to this page to download the desktop tool).*

### 2. Download the Desktop App
- Go to the [Latest Releases](https://github.com/HAMSypg/YT-Downloader/releases/latest) page.
- Download the `YT-Downloads-Pro.exe` file.
- Run the application on your Windows PC.

### 3. Activate Smart Integration
Once the app is open, click on **"Activate Smart Install"** (or **تفعيل التثبيت التلقائي**). This registers the protocol on your Windows system so the browser can communicate with the app.

## 🏗️ Technical Stack

*   **Backend:** [Python 3.14](https://www.python.org/)
*   **Engine:** [yt-dlp](https://github.com/yt-dlp/yt-dlp)
*   **UI Framework:** [pywebview](https://pywebview.flowrl.com/) (HTML5/CSS3/JS)
*   **Extension:** JavaScript (Manifest V3)
